# Chess Academy Mobile

An original mobile-first chess education app built with Expo and React Native.

## Included
- **Tasks:** a progressive learning route with five original tactical and strategic multiple-choice exercises, answer checking, explanations and coach tips.
- **Learning:** five original lessons covering chess basics, piece values, tactics, opening plans and endgames.
- Coach dialogue cards, animated transitions, a pulsing current lesson marker and learner progress.
- No playable chess game.
- No advertising SDK, ad placements, VIP tier, paywall or in-app purchases.
- No copied app artwork, characters, branding, lesson text or proprietary assets.

## Run locally
```sh
npm install
npx expo start
```
Open the QR code in Expo Go, or run on an Android/iOS simulator.

## Prototype notes
Progress is currently kept in memory while the app is open. Persistent local storage, accessibility review, device QA and production app identifiers are follow-up release tasks.
